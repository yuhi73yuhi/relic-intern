# GrooveLens

先生のお手本と自分の演奏をスマホで録音すると、**「どこが・何が・どれだけ」惜しいのか**が並べて見えるグルーヴ練習アプリ（MVP）。
解析はすべてブラウザ内の Web Audio API で完結し、音声はサーバーに送信されません。

## 起動

```bash
npm install
npm run dev
```

http://localhost:3000 を開き、楽器とジャンルを選んで「デモ音源をロード」を押してください。

## 画面の見方

| エリア | 内容 |
| --- | --- |
| 楽器 × ジャンル | ドラム / ベース / ギター（ファンク・ロック）、ピアノ（ジャズ・ポップス）、ボーカル（ポップス・バラード）。選択に合わせて拍のグリッド・判定の物差し・見るニュアンスが切り替わる |
| 先生のお手本 / あなたの演奏 | ファイル読み込み・マイク録音。録音品質（音割れ・音量・雑音）を自動チェック |
| グルーヴ一致度 | 0〜100点。惜しいポイント上位3つを直した場合の見込み点も表示 |
| 惜しいポイント | 直すと何点上がるか順に並べる。「2・4拍目が平均 -27ms 早い（8回中8回）→ +6点」のように、位置・観点・量・練習方法をセットで提示 |
| 波形を並べて比較 | 先生と自分の波形を上下に並べ、1音ごとのズレを表示。クリックで音を選択 |
| ニュアンス・マップ | 1音ごとに タイミング / 強弱 / アタック / 音の長さ（ボーカルはピッチも）を色分け表示 |
| ノート詳細 | 選んだ1音の「音の形」（立ち上がり・減衰）を重ねて表示し、先生とあなたを交互に聴き比べ |
| 総評 | 先生比とメトロノーム比のズレ、ばらつき、強弱の幅、スウィング比（ジャズ） |
| 精度検証 | スマホ録音相当の劣化を加えた正解つき演奏で、測定誤差を検証 |

## 解析の仕組み（`src/lib/groove.ts`）

1. 全帯域と高域強調（1次差分）の2つの振幅エンベロープの立ち上がりから、音の候補を検出
2. 前の音の余韻との「谷」を見つけ、谷→ピークの20%を超えた点から発音の開始点を外挿（誤差 1〜3ms）
3. 各音について 強さ（ピーク）・アタック（20→90%の時間）・音の長さ（-16dBまで減衰する時間）・ピッチ（YIN、ボーカルのみ）を計測
4. 動的計画法で先生と自分の音を対応付け、ジャンルの基準テンポ付近でグリッドを当てはめて小節・拍を推定
5. 各観点の差を「判定の物差し」で正規化して採点。拍内の位置ごとに毎回同じ方向へズレる「癖」を抽出し、直した場合のスコア上昇で順位付け

## 構成

| パス | 役割 |
| --- | --- |
| `src/app/page.tsx` | ダッシュボード |
| `src/lib/profiles.ts` | 楽器 × ジャンルの定義（判定の物差し・検出パラメータ・練習アドバイス） |
| `src/lib/groove.ts` | オンセット検出・特徴量・対応付け・スコア・惜しいポイント・総評 |
| `src/lib/synth.ts` | デモ音源の合成（先生／生徒）とスマホ録音シミュレーション |
| `src/lib/accuracy.ts` | 精度検証 |
| `src/lib/quality.ts` | 録音品質チェック |
| `src/components/` | 各パネル |
